# ⚙️ Core Implementation (VERY IMPORTANT)

## 1. Extend Interpreter (interpreter.js)

Add support for:

### A. setTimeout

* Detect CallExpression with callee `setTimeout`
* Extract callback function
* Push into:
  → macrotaskQueue = []

Log:
→ "setTimeout registered → moved to Macrotask Queue"

---

### B. Promise.resolve().then

Support ONLY this pattern:

```js
Promise.resolve().then(callback)
```

* Detect MemberExpression → then
* Push callback into:
  → microtaskQueue = []

Log:
→ "Promise.then registered → moved to Microtask Queue"

---

## 2. Data Structures

Maintain:

```js
const callStack = [];
const microtaskQueue = [];
const macrotaskQueue = [];
```

---

## 3. Execution Flow (Simulation Engine)

### Phase 1: Synchronous Execution

* Execute all normal statements
* Populate queues

---

### Phase 2: Event Loop Simulation

After call stack is empty:

#### Step 1: Process Microtasks

* While microtaskQueue not empty:

  * dequeue
  * execute callback
  * log output

#### Step 2: Process Macrotasks

* Take ONE macrotask
* execute it
* after execution:

  * again process all microtasks

---

## 4. Logging Rules (IMPORTANT)

Every major step must be logged:

Examples:

* "Call Stack → console.log"
* "Moved to Microtask Queue"
* "Processing Microtasks"
* "Processing Macrotasks"
