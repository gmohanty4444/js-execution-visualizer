Extend the existing **“JS Execution Visualizer”** (Week 1 + Week 2) by adding an **“Expectation vs Reality” learning layer**.

This feature allows users to:

1. Predict output before execution
2. Compare with actual output
3. See a clear explanation of WHY they were wrong (or right)

---

# 🎯 Goal

Turn the tool into an **interactive interview practice system**, not just a simulator.

---

# 🧩 Features (STRICTLY WEEK 3)

## 1. User Prediction Input (Frontend)

Before running code, prompt user:

UI:

* Text input OR ordered list input
* Label:
  → “What do you think the output will be?”

Example input:

```text id="e9f8o4"
start
timeout
promise
end
```

Store as:

```json id="8h7f9c"
{
  "predictedOutput": ["start", "timeout", "promise", "end"]
}
```

---

## 2. Backend Comparison Engine

Extend `/analyze` API:

### Input:

```json id="93j2kd"
{
  "code": "...",
  "predictedOutput": ["..."]
}
```

### Output:

```json id="4k9x2p"
{
  "actualOutput": ["start", "end", "promise", "timeout"],
  "predictedOutput": ["start", "timeout", "promise", "end"],
  "isCorrect": false,
  "diff": [
    {
      "index": 1,
      "expected": "end",
      "got": "timeout",
      "reason": "Macrotask executed before microtask in prediction"
    }
  ],
  "concepts": ["event loop", "microtask queue", "macrotask queue"]
}
```

---

## 3. Output Extraction (IMPORTANT)

Modify interpreter:

* Capture ONLY console.log outputs into:

```js id="a7c2m1"
const actualOutput = [];
```

* Example:

```js id="l3p0q9"
actualOutput.push("start");
```

---

## 4. Diff Algorithm

Compare arrays:

* If lengths differ → mark incorrect
* Compare index by index
* Generate mismatch objects:

```js id="v8d4x0"
{
  index: i,
  expected: actualOutput[i],
  got: predictedOutput[i]
}
```

---

## 5. Reason Generator (Rule-Based, NOT AI)

Do NOT use LLM yet.

Create simple rule mapping:

### Rules:

IF:

* Promise involved
* setTimeout involved
* wrong order between them

THEN:

```text id="t7z9r2"
"Microtasks (Promises) execute before macrotasks (setTimeout)"
```

---

IF:

* variable logged before assignment

THEN:

```text id="h2y6k1"
"Variable is hoisted and initialized as undefined"
```

---

Map detected AST patterns → explanation strings

---
